# نايل – Nile Egyptian Search 🇪🇬

محرك بحث عربي مصري متكامل وعصري، مصمم خصيصاً للمستخدمين في مصر والوطن العربي، مع أولوية مطلقة للمصادر المصرية الرسمية، والتغطيات الإخبارية الموثقة، وبوابات الخدمات الحكومية، والتراث السياحي، بدون تزييف نتائج أو روابط وهمية.

---

## 🌟 أبرز مميزات نايل (Features)

1. **واجهة عربية أصيلة (RTL)**:
   - تصميم متجاوب فائق السرعة يعتمد خطوط `Cairo` و `Readex Pro`.
   - استخدام أنيق لهوية العلم المصري باللونين الأسود والأحمر والنسر الذهبي.
   - التزام كامل بمعايير التصميم الخالية من الحشو الزائف (Anti-AI Slop / Clean Unboxed Metadata).

2. **نتائج ويب حقيقية ومحدثة (100% Real Web Results)**:
   - لا توجد أي نتائج مفبركة أو روابط وهمية.
   - دمج محركات متعددة في طبقة موحدة:
     - **Google News Egypt RSS**: تغطية إخبارية حية ومباشرة للشأن المصري من الصحف الرسمية والمستقلة (الأهرام، اليوم السابع، الشروق، المصري اليوم، بي بي سي عربي).
     - **ويكيبيديا العربية (Arabic Wikipedia API)**: بطاقات معرفية موثقة وصور عالية الجودة بروابط مباشرة.
     - **DuckDuckGo Web Index**: فهرس بحث ويب عالمي حقيقي يحترم الخصوصية وبدون مفاتيح مدفوعة.
     - **سجل الجهات المصرية المعتمدة**: بطاقات تعريفية للوزارات والبنك المركزي والأندية الرياضية مع الخطوط الساخنة والعناوين والخدمات الرقمية.

3. **تصنيفات البحث (Search Tabs)**:
   - **الكل**: نتائج الويب والمصادر الرسمية وبطاقات المعرفة.
   - **الأخبار المصرية**: تغطيات حية للحظة بلحظة.
   - **الخدمات الحكومية**: تركيز على بوابات مصر الرقمية، التموين، الصحة، والتوثيق.
   - **الصور**: معرض صور حقيقي وموثق مع عرض تفصيلي ومقاسات ومصدر الصورة.
   - **الفيديو**: فيديوهات وتقارير مرئية من منصات الفيديو والتلفزيون المصري.

4. **مؤشرات مصرية حية (نبض مصر - Egyptian Widgets)**:
   - أسعار صرف العملات مقابل الجنيه المصري (الدولار، اليورو، الريال السعودي، الدرهم الإماراتي، الدينار الكويتي).
   - حاسبة تحويل الدولار للجنيه المصري لحظياً.
   - أسعار الذهب في الصاغة المصرية (عيار 24، عيار 21، عيار 18، الجنيه الذهب).
   - مواقيت الصلاة في القاهرة والمحافظات وفقاً للهيئة المصرية العامة للمساحة.
   - درجات الحرارة والطقس في القاهرة والمحافظات.

5. **الخصوصية وسجل البحث (Search History & Privacy)**:
   - سجل بحث محلي مشفر ومحفوظ فقط في جهاز المستخدم (LocalStorage).
   - إمكانية حذف أي استعلام أو تفريغ السجل بالكامل بضغطة زر.
   - عدم تتبع المستخدمين أو بيع البيانات أو وضع ملفات تعريف ارتباط إعلانية.

## 🚀 طريقة التشغيل والإعداد (Quick Start)

### المتطلبات الأساسية
- Node.js (الإصدار 20 أو أحدث)
- npm أو yarn أو pnpm

### خطوات التشغيل
1. تثبيت الاعتماديات:
```bash
npm install
```

2. تشغيل خادم التطوير (Full-stack مع خادم Express مدمج مع Vite):
```bash
npm run dev
```
سيعمل التطبيق مباشرة على المنفذ `http://localhost:3000`.

3. البناء للإنتاج (Production Build):
```bash
npm run build
npm start
```

## 🔑 إعداد مزودات البحث الاختيارية (API Configuration)

> 💡 **ملاحظة مهمة**: محرك بحث «نايل» يعمل مباشرة بشكل كامل ومجاني بدون الحاجة لإدخال أي مفاتيح API، معتمداً على المصادر الحرة المدمجة (Google News RSS Egypt, Arabic Wikipedia, DuckDuckGo, Egyptian Directory).

إذا رغبت في تفعيل **Google Custom Search JSON API** كطبقة إضافية:
1. توفر شركة Google باقة مجانية دائمة تمنحك **100 عملية بحث يومياً دون أي تكلفة**.
2. أنشئ مشروعاً في [Google Cloud Console](https://console.cloud.google.com) وفعّل خدمة `Custom Search API`.
3. انسخ المفتاح وضعه في ملف `.env`:
```env
GOOGLE_SEARCH_API_KEY="مفتاح_API_الخاص_بك"
```
4. أنشئ محرك بحث في [Google Programmable Search Engine](https://programmablesearchengine.google.com) وحدد البحث في الويب كاملاً، وانسخ معرف المحرك (Search Engine ID):
```env
GOOGLE_SEARCH_CX="معرف_المحرك_الخاص_بك"
```
5. أعد تشغيل التطبيق؛ وسيتعرف الخادم تلقائياً على المفتاح ويدمجه في نتائج البحث.

## 🧪 الاستعلامات الخمسة الموصى باختبارها (Test Suite)

تم تصميم النظام لاختبار وتحقيق نتائج نموذجية حقيقية لهذه الاستعلامات الخمسة:
1. **وزارة الصحة المصرية**: تعرض بطاقة الجهة الرسمية المعتمدة، موقع `mohp.gov.eg`، الخط الساخن 105، روابط 100 مليون صحة، وأحدث الأخبار.
2. **أخبار مصر اليوم**: تغذية حية من كبرى الصحف المصرية (الأهرام، اليوم السابع، الشروق) بمقالات حقيقية وتوقيت النشر.
3. **السياحة في الأقصر**: معابد الكرنك ووادي الملوك، حجز تذاكر المتاحف، وبوابة وزارة السياحة والآثار `egymonuments.gov.eg`.
4. **النادي الأهلي المصري**: البوابة الرسمية للنادي الأهلي `alahlyegypt.com`، مواعيد المباريات، القناة الرسمية، والمتجر.
5. **البنك المركزي المصري**: أسعار الصرف الرسمية، قرارات لجنة السياسة النقدية، بوابة البنك `cbe.org.eg`، وتطبيق إنستاباي.
